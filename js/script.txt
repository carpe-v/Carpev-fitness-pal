CARPEV FITNESS V2 - Sistem Filtre Include / Exclude

Vreau implementarea unui sistem generic de filtre reutilizabil în toată aplicația.

Principiu

Fiecare tag are 3 stări:

Plain Text
Neutral
Include
Exclude

Comportament click:

Plain Text
Neutral
↓
Include
↓
Exclude
↓
Neutral
 

Vizual:

Plain Text
⚪ Neutral
 
🟢 Include
 
🔴 Exclude

Sistemul trebuie să păstreze separat:

Plain Text

Reguli

Dacă nu există filtre Include:

Plain Text
Se afișează toate rezultatele.

Dacă există filtre Include:

Plain Text
Se afișează doar elementele care se potrivesc.

Dacă există filtre Exclude:

Plain Text
Se elimină rezultatele care conțin acele taguri.
Exemplu 1

Filtre:

Plain Text
✅ Piept
✅ Triceps

Rezultat:

Plain Text
Toate exercițiile pentru Piept sau Triceps.
Exemplu 2

Filtre:

Plain Text
✅ Piept
 
❌ Smith
❌ Cablu

Rezultat:

Plain Text
Exerciții pentru Piept
dar fără Smith și fără Cablu.
Exemplu 3

Filtre:

Plain Text
✅ Spate
 
✅ Liber
 
❌ Avansat

Rezultat:

Plain Text
Exerciții pentru Spate,
executate liber,
care nu sunt marcate ca avansate.
